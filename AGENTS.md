# Repository startup instructions

Read `../AGENTS.md` and `../PROJECT_PROGRESS.md` before working on this project,
at every task start and after compaction/resume. Follow the parent instructions
and update the shared progress log after every meaningful action and before
ending the turn. This repository entry point also applies when it is opened
separately as the working directory; do not create a competing progress log.

The active R5 board differs from portions of this checkout. Consult the
board-matched overlays in `../risabot5_snapshots/20260923_wifi_start/` before
deploying. Do not treat an older source file or pending-action note as the
current deployed state.
